This page presents detailed results on the router IPv6 addresses discovered using Subnet-Router anycast (SRA) probing. We provide a historical development plot, geographic distributions of router IPv6 addresses, and a network type distribution.

SRA candidate set generation pipeline

This diagram illustrates the process to generate target IPv6 addresses for scanning. We use (i) the TU Munich hitlist addresses they use for scanning and derive all unique /64 networks, and (ii) all /48 BGP announcements for which we then generate all possible /64 subnets.

Generation of Subnet-Router anycast addresses

This diagram illustrates how we generate the Subnet-Router anycast (SRA) address for a given IPv6 subnet. The SRA address is formed by setting the interface identifier to the fixed value of ::0 within the subnet, we then iterate over all possible /64 subnets and derive the SRA address for each.
